AI Student Assistant Chatbot

Project Overview:

AI Student Assistant Chatbot is an AI-powered web application designed to help students with their academic activities. The chatbot can answer study-related questions, provide programming help, and assist with learning.

 Objectives:
- Answer students' academic questions
- Provide programming assistance
- Help students understand different courses
- Support study planning

Planned Features:
- AI Chatbot
- Course Information
- Programming Help
- Study Planner
- FAQ Section

Technologies:
- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API


Currently in the Planning Phase.The project structure and features may be updated or deleted during development.
